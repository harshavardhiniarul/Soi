## How to Use This Repository

### **For Project Reviewers**
1. Navigate to the evidence folder link provided in the Phase 1 deck (Slide 4).
2. Cross-reference each Evidence ID (E09–E12b) with the links and summaries in this README.
3. Verify that cited evidence supports the claims made on each slide.
4. Check the "Status" column for completed vs. planned evidence.

### **For Stakeholder Interviews (Phase 2)**
1. As interviews are conducted (E01–E08), anonymized notes will be added to a private subfolder.
2. Each interview will be assigned an ID (E01, E02, etc.) and documented with:
   - Date of conversation
   - Stakeholder role (anonymized)
   - Key findings related to delay factors
   - Consent record (verbal or written)
3. All personal identifiers will be removed; only role, context, and findings retained.

### **For Data Access & Technical Validation**
- E10a (OGD Platform) provides public access to project-level delay data.
- District revenue office access (if granted) will be documented separately with formal data-sharing agreements.
- Synthetic dataset creation plan will be documented if real data access is delayed beyond Phase 2.

## Evidence Quality Standards

✓ **All sources are:**
- Publicly available (no confidential or personal data)
- Authored by recognized institutions (government, parliamentary committees, peer-reviewed journals)
- Published within the last 7 years (except foundational research)
- Directly relevant to the problem statement
- Anonymized where necessary (for interviews)

✗ **Sources excluded:**
- Internal government memos without official publication
- Personal communications without written consent
- Speculative or non-peer-reviewed sources
- Data containing landowner names or case file details
